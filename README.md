# 🍹 CocktailCalc Pro

Приложение для расчёта закупок коктейлей. Работает как веб-интерфейс и как Telegram-бот, используя одну общую базу данных.

## Структура

```
cockt_bot_refactored/
├── data/
│   └── cocktails_db.json          # Единая база коктейлей, ПФ, цен и категорий
├── cocktail_calc/                 # Общее ядро расчётов
│   ├── models.py
│   ├── repository.py
│   ├── calculator.py
│   └── config.py
├── web/                           # Веб-интерфейс (FastAPI)
│   ├── main.py
│   ├── static/style.css
│   └── templates/
├── web_static/                    # Статическая демо-версия (HTML + JS)
│   └── index.html
├── bot/                           # Telegram-бот
│   ├── main.py
│   └── handlers.py
├── requirements.txt
└── README.md
```

## Быстрая проверка без Python

Если Python ещё не установлен, можно открыть статическую демо-версию прямо в браузере:

```
web_static/index.html
web_static/admin.html
```

Просто дважды кликни по файлу — откроется страница. База хранится в одном файле `web_static/db.js`, который читают обе страницы.

- `index.html` — калькулятор закупок.
- `admin.html` — редактор базы: коктейли, ПФ, ингредиенты. После редактирования нажми «Скачать JSON» и замени им `data/cocktails_db.json`.

### Как обновить статические HTML после правки JSON

Если ты редактируешь `data/cocktails_db.json` вручную или через FastAPI-админку, и хочешь, чтобы статические HTML-страницы тоже показывали новую базу:

**Вариант 1 — двойной клик (Windows):**

Открой папку `cockt_bot_refactored` и дважды кликни по `update_static.bat`. Он обновит `web_static/db.js`.

**Вариант 2 — командная строка:**

```bash
cd cockt_bot_refactored
python update_static.py
```

Если `python` не работает, попробуй:

```bash
python3 update_static.py
```

или

```bash
py update_static.py
```

После этого обнови страницы `index.html` и `admin.html` в браузере.

```bash
pip install -r requirements.txt
```

## Запуск веб-интерфейса

```bash
uvicorn web.main:app --reload
```

Открой в браузере: http://127.0.0.1:8000

## Запуск Telegram-бота

1. Получи токен у [@BotFather](https://t.me/BotFather).
2. Запусти бота с токеном:

```bash
set BOT_TOKEN=твой_токен
python -m bot.main
```

Или через PowerShell:

```powershell
$env:BOT_TOKEN="твой_токен"
python -m bot.main
```

## Админка для базы данных

После запуска веб-интерфейса открой в браузере:

```
http://127.0.0.1:8000/admin
```

- Логин: `admin`
- Пароль: `admin`

На странице «База» можно:
- редактировать коктейли и полуфабрикаты,
- добавлять новые позиции,
- удалять позиции,
- редактировать категории, цены и объёмы бутылок для ингредиентов,
- сохранять изменения в `data/cocktails_db.json`,
- создавать бэкапы (автоматически перед каждым сохранением).

Изменения применяются сразу и в веб-интерфейсе, и в Telegram-боте.

### Категории ингредиентов

- `алкоголь` — считается бутылками по `bottle_volumes`
- `безалкогольное`, `пюре`, `концентрат` — считается за литр
- `сироп` — считается бутылками
- `сухой_гр` — считается в граммах, цена за кг
- `лёд_кубик` — считается в кг
- `лёд_фигурный` — считается в штуках
- `украшение_шт` — штуки
- `украшение_гр` — граммы
- `посуда` — только количество, без цены

## Формат заказа

В веб-интерфейсе заказ формируется только через выбор коктейлей из базы: нажми на карточку или укажи количество вручную.

В Telegram-боте заказ можно отправить текстом в формате:

```
Кокосовый ром 10, Мохито 5, Негрони 3
```

Можно через запятую или с новой строки.
